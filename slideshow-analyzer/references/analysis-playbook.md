## The Three Layers

Always work top-down:

1. **Why would someone share this?** — Pick the mechanism first. Never compromise this.
2. **How is it delivered?** — Narrative structure, humor type, slide relationship. Should vary between variants.
3. **What do you see?** — Specific characters, scenes, fonts, text. Last decisions, most replaceable.

**Anti-pattern**: Starting from "let's use a cat" produces clones, not innovations.

## Four Archetypes

Pick one before doing anything else. It determines which rules apply.

### Archetype Overview

| | Character-Action | Tension-Punchline | Emotional Arc | Mood Showcase |
|---|---|---|---|---|
| **Each slide is...** | An independent visual gag | A pacing device building toward the punchline | A beat in an emotional journey | A facet of a curated aesthetic |
| **Core output** | Humor (per-slide) | Humor (cumulative) | Feeling (empathy, hope, longing) | Vibe (aspiration, identity, belonging) |
| **Slides connected?** | Usually no | Usually yes (zoom / pan / progression) | Yes — emotional state changes | Loosely — unified by mood, not narrative |
| **Each image standalone?** | Required (>=50% must pass "cover the text" test) | Not required — images serve the sequence | Required — each must evoke emotion alone | Required — each must be "saveable" alone |
| **Contrast stacking** | Required (>=2 dimensions) | Not required | Not required — contrast is emotional (before/after, pain/hope) | Not required |
| **Text role** | Carries the joke alongside image | Delivers the punchline | Narrates the emotional shift | Labels the mood or stays absent |
| **Example** | Case 001 (hamster), Case 004 (cat) | Case 006 (monkey plush), Case 007 (Daumier painting) | Skincare Split-Screen, Pet Care POV | Stoic Minimalist, Lifestyle Curation, Productivity Grid |

### When to pick which

| If the slideshow... | Pick |
|---------------------|------|
| Makes you laugh slide-by-slide | **Character-Action** |
| Builds suspense then surprises you | **Tension-Punchline** |
| Makes you feel something (sad, hopeful, seen) | **Emotional Arc** |
| Makes you want to save/screenshot for the aesthetic | **Mood Showcase** |

### Quality Checklist

| Check | Char-Action | Tension-Punch | Emotional Arc | Mood Showcase |
|-------|:---:|:---:|:---:|:---:|
| Does the spike trigger the intended mechanism? | Yes | Yes | Yes | — (no spike) |
| Would someone screenshot/save and send to a friend? | Yes | Yes | Yes | Yes (save) |
| Does it look like a previous case with different words? | No | No | No | No |
| Can this vehicle carry this mechanism? | Yes | Yes | Yes | Yes |
| Cover the text — is each image still interesting? | Yes | — | Yes | Yes |
| Contrast stack >= 2 dimensions? | Yes | — | — | — |
| Does Slide 0 create "I need to know" anticipation? | — | Yes | — | — |
| Does each swipe feel like physical progression? | — | Yes | — | — |
| Does the final slide break the established pattern? | — | Yes | — | — |
| Does each slide deepen the emotional state? | — | — | Yes | — |
| Is there a clear emotional turn (pain->hope or loss->found)? | — | — | Yes | — |
| Would someone save this to a mood board or Pinterest? | — | — | — | Yes |
| Does every slide belong to the same visual world? | — | — | — | Yes |

## Trigger Types

Before matching a specific mechanism, first identify **what type of psychological trigger** drives this slideshow. This is the upstream question — it tells you where to look for the mechanism.

Five-step decision flow (ask in order, stop at the first "yes"):

| Step | Question | If yes → Trigger type |
|------|----------|----------------------|
| 1 | Is it delivering useful information or proving a result? | **Rational** (problem-solution, proof, comparison, education) |
| 2 | Is it building trust through people or identity? | **Social** (influencer, testimonial, identity, lifestyle) |
| 3 | Is it selling a desirable lifestyle, aesthetic, or state-of-being? | **Aspirational** (mood, atmosphere, "I want that life", aesthetic curation) |
| 4 | Is it deliberately provoking curiosity, emotion, or laughter? | **Emotional / Instinct** (curiosity hook, meme/humor, emotional resonance, scarcity, contrarian) |
| 5 | Is it just documenting or following a trend? | **Behavioral** (documentation, trend replication) |

**Aspirational vs Social vs Emotional** — the tricky boundaries:

| Trigger | Core question the viewer asks | Sharing motive |
|---------|-------------------------------|----------------|
| Social | "Do I trust this person?" | Endorsement / credibility |
| Aspirational | "Do I want this life?" | Self-projection / goal-setting |
| Emotional | "Do I feel something?" | Catharsis / connection / humor |

A slideshow can stack triggers — e.g., Case 006 is **Instinct** (curiosity: "come closer") + **Emotional** (meme: monkey behavior pun). Identifying all active triggers helps you understand what's really driving shares.

**Why this matters for derivation**: The trigger type is **soul** — change it and the slideshow stops working. The specific mechanism is how the trigger is delivered.

Examples:

| Case | Primary trigger | Specific mechanism |
|------|----------------|-------------------|
| 001 | Emotional (meme/humor) | Forbidden Release + Absurd Intrusion |
| 004 | Emotional (emotional resonance + meme) | Proxy Expression + Doom Spiral |
| 006 | Instinct (curiosity) + Emotional (meme) | Parasocial Bait-and-Switch |
| 007 | Emotional (meme) + Social (identity) | Dignity Mismatch + Proxy Expression |
| Skincare Split-Screen | Emotional (empathy) | Emotional Mirror + Transformation Proof |
| Stoic Minimalist | Aspirational (atmosphere) | Aspirational Pull |
| BookTok Curation | Aspirational (identity) + Social (tribe) | Identity Signal |
| Pet Care POV | Emotional (empathy) | Transformation Proof |
| Productivity Grid | Rational (inspiration) + Aspirational (identity) | Utility Bookmark + Identity Signal |
| 008 (Study Methods) | Rational (education/proof) + Aspirational (studygram aesthetic) | Utility Bookmark + Aspirational Pull |

## Mechanism Library

Each mechanism answers: "Why would someone share this?"

### "Say it for me" (Proxy Expression)

A character expresses what the viewer feels but won't say directly.
- Viewer feels: "Finally someone said it" (relief)
- Sharing says: "This is me" (self-identification without vulnerability)
- Example: Case 004 — cats acting out "brain not braining, sleep not sleeping"

### "I wish I could do that" (Forbidden Release)

A character does something socially forbidden; viewer gets vicarious satisfaction.
- Viewer feels: "I wish I could do that" (catharsis)
- Sharing says: "Look at this absolute legend"
- Example: Case 001 — hamster giving middle finger at work

### "That doesn't belong there" (Absurd Intrusion)

Something fundamentally out of place appears in a normal setting.
- Viewer feels: "This is so ridiculous" (delight)
- Sharing says: "You need to see this"
- Example: Case 001 — tiny hamster in human-sized cubicle

### "It keeps getting worse" (Escalating Doom Spiral)

A sequence of increasingly bad situations mirroring real overwhelm.
- Viewer feels: "It keeps getting worse, just like my life" (dark humor catharsis)
- Sharing says: "Tag someone whose life is like this"
- Example: Case 004 — brain → study → sleep → money → love → hate spiral

### "Come closer, I have a secret" (Parasocial Bait-and-Switch)

Simulates intimate interaction, builds anticipation, then subverts with a punchline that IS the ad.
- Viewer feels: Curiosity → "I got played but it was fun"
- Sharing says: "I fell for this, now you fall for it too"
- Example: Case 006 — monkey plush whispering "come closer" → zoom in → ad punchline

### "Dramatically unimportant" (Dignity Mismatch)

Elevates a mundane modern behavior to a high-status or historical context.
- Viewer feels: "This is so ridiculously dramatic" (amused recognition)
- Sharing says: "This is literally me right now"
- Example: Case 007 — 19th century courtroom painting × "she's been on TikTok for 45mins"

### Non-Humor Mechanisms

The mechanisms above are humor-driven. The following mechanisms drive shares through emotion, aspiration, or identity — equally powerful, different psychology.

### "I feel seen" (Emotional Mirror)

Visualizes a pain point, struggle, or emotional state so precisely that the viewer feels understood without words.
- Viewer feels: "This is exactly what it's like" (validation)
- Sharing says: "You need to understand what I go through"
- Archetype fit: **Emotional Arc**
- Example: Skincare Split-Screen — same girl in same room, top half glowing and happy, bottom half dark and defeated with acne. No text needed.

### "I want that life" (Aspirational Pull)

Presents a lifestyle, environment, or state-of-being so desirable that the viewer saves it as a goal.
- Viewer feels: "One day, that will be me" (longing + motivation)
- Sharing says: "This is the vibe I'm working toward"
- Archetype fit: **Mood Showcase**
- Example: Stoic Minimalist — dark cinematic shots progressing from lonely bedroom to Dubai skyline to airplane window. No characters, pure atmosphere.

### "This is who I am" (Identity Signal)

Curates objects, aesthetics, or activities that signal belonging to a specific tribe or taste community.
- Viewer feels: "These are my people" (belonging + self-expression)
- Sharing says: "If you get this, we're the same"
- Archetype fit: **Mood Showcase**
- Example: BookTok Curation — grid collages of dark romance novels + fantasy art + couple silhouettes. Sharing = declaring your reading identity.

### "Look what happened" (Transformation Proof)

Shows a before/after or journey that proves change is possible, making the viewer believe they can achieve it too.
- Viewer feels: "If they can do it, maybe I can too" (hope + motivation)
- Sharing says: "This is inspiring / this is proof it works"
- Archetype fit: **Emotional Arc**
- Example: Pet Care POV — cats in shelter cage (before) to cats on plush bed at home (after). The transformation IS the story.

### "Save this for later" (Utility Bookmark)

Delivers genuinely useful information or inspiration in a visually appealing format that demands bookmarking.
- Viewer feels: "I need to remember this" (practical value)
- Sharing says: "You'll thank me later"
- Archetype fit: **Mood Showcase** or **Character-Action** (when humor + utility combine)
- Example: Productivity Grid — each slide showcases a different creative setup (makeup studio, art supplies, workspace). Useful reference + aesthetic inspiration.

---

A slideshow often combines multiple mechanisms. Identify the **primary** one (reason someone shares) and any **secondary** ones (reasons someone keeps swiping). Humor and non-humor mechanisms can coexist — e.g., a meme slideshow (Proxy Expression) that also functions as a useful list (Utility Bookmark).

## Vehicle Compatibility

Not every character can play every role. **Check before committing.**

### Humor Mechanisms

| Mechanism | Vehicle needs... | Good | Bad |
|-----------|-----------------|------|-----|
| "Say it for me" | Expressive face that receives emotional projection | Cats, dogs, babies, cartoon characters | Plain objects without faces |
| "I wish I could do that" | Body capable of human-like forbidden gestures | Small animals with paws, AI mini-humans | Scenery, abstract art |
| "That doesn't belong there" | Subject that clearly doesn't belong | Tiny animals in human spaces, fantasy creatures in offices | Anything plausible in that setting |
| "It keeps getting worse" | Ability to show visual progression | Characters in worsening situations | Single static subjects |
| "Come closer" | Endearing character with fixed expression + self-referential pun opportunity | Plush toys, figurines, pets with smug faces | Generic stock photos |
| "Dramatically unimportant" | High-gravitas visual context | Classical paintings, royal portraits, epic movie stills | Casual modern photos |

### Non-Humor Mechanisms

| Mechanism | Vehicle needs... | Good | Bad |
|-----------|-----------------|------|-----|
| "I feel seen" (Emotional Mirror) | Visual that can show two contrasting states of the same subject | Illustrated characters (same person, different mood), split-screen photos, before/after | Abstract art, unrelated image pairs |
| "I want that life" (Aspirational Pull) | Atmospheric imagery that sells a lifestyle without showing product | Cinematic photography (dark rooms, city skylines, travel), luxury interiors, moody landscapes | Bright stock photos, cluttered scenes, anything that looks "normal" |
| "This is who I am" (Identity Signal) | Curated objects/aesthetics that signal tribe membership | Grid collages of books/art/fashion, flat-lays of niche hobbies, aesthetic mood boards | Generic lifestyle photos, anything that could belong to anyone |
| "Look what happened" (Transformation Proof) | Subject that can show clear before → after change | Real photos of same pet/person/space at different times, progress shots | Stock photos, unrelated images pretending to be the same subject |
| "Save this for later" (Utility Bookmark) | Visually organized useful information | Multi-angle product shots, workspace setups, tool collections, recipe steps | Walls of text, low-quality screenshots |

**Rule**: If the vehicle can't carry the mechanism, no amount of clever text will save it. Change the vehicle.

### Face Rules by Archetype

**For Character-Action and Tension-Punchline**: Meme Face > Pretty Face. The character must have **meme-grade expressiveness** — exaggerated, imperfect, slightly absurd. "Nice photo of a cat" = not meme-grade. "Look at this idiot" = meme-grade.

| Good (meme face) | Bad (pretty face) |
|-------------------|-------------------|
| Squinting judgmentally, side-eye | Alert, attentive, "good pet" pose |
| Derp face, tongue out, cross-eyed | Symmetrical, photogenic face |
| Mouth slightly open in dumb surprise | Mouth closed, composed |
| Caught mid-yawn or mid-sneeze | Perfectly still, posed |
| Sprawled in undignified position | Sitting neatly, poised |

**For Emotional Arc**: Authentic Face > Meme Face. Expressions should feel real and relatable, not exaggerated. Illustrated characters should show genuine sadness, hope, or relief — not comedy.

**For Mood Showcase**: No Face Required. The vehicle is often environments, objects, or curated collections. When people appear, they're silhouettes, partial views, or lifestyle shots — never the focus.

## Slide Structure

Two orthogonal dimensions define a slideshow's structure. Both are **soul** — change either and the slideshow breaks.

### Visual Continuity (how slides look together)

| Strength | Test | Effect |
|----------|------|--------|
| **Strong (single-image split)** | Could you stitch slides back into one continuous image? | Swipe = physically panning across one scene |
| **Medium (shared scene)** | Same setting, some elements cross borders, but not one source image | Swipe = moving within a world |
| **Weak (thematic only)** | Same style but no physical spatial connection | Swipe = page turn with visual consistency |

**Continuity by archetype**:
- **Tension-Punchline**: Strong continuity is usually essential — it's what makes the swipe feel meaningful.
- **Character-Action**: Weak continuity is fine — each slide is independent.
- **Emotional Arc**: Medium continuity works best — same world, changing emotional state.
- **Mood Showcase**: Weak continuity is the norm — unified by aesthetic, not space.

**Design principle**: For Tension-Punchline, the final slide should **break the established pattern** (text appears where the next zoom step was expected). For Emotional Arc, the final slide should **resolve the emotional tension** (hope after pain, home after shelter). For Mood Showcase, the final slide should **be the most saveable image** or a CTA.

### Information Format (what role each slide plays)

| Format | Each slide is... | Can you shuffle the order? | Example |
|--------|------------------|---------------------------|--------|
| **List** | One item in a set | Yes, order doesn't matter | "Top 5 tools", Case 001 (Work / Fitness / Commute) |
| **Step-by-step** | One step in a process | No, sequence is critical | App tutorial, how-to guide |
| **Story** | One plot beat | No, causality matters | Case 004 (brain → study → sleep → money → love → hate) |
| **Comparison** | One side of A-vs-B or Before/After | Partially (pairs stay together) | Before/After transformation |
| **Zoom progression** | A tighter crop of the same subject | No, distance must decrease | Case 006 (full body → medium → close-up → extreme close-up) |
| **Showcase** | One angle/scene of the same subject | Yes, no narrative dependency | Product multi-angle gallery |
| **Q&A** | One question-answer pair | Yes between pairs, no within pair | FAQ slideshow |
| **Parallel Contrast** | Two states of the same scene (good/bad, before/after) shown simultaneously per slide | No — emotional arc matters | Skincare Split-Screen (top = glowing, bottom = struggling) |
| **Mood Board / Grid** | A multi-image collage exploring one theme from multiple angles | Yes between slides, no within a grid | BookTok Curation (4 images per slide: books + art + aesthetic) |
| **Atmospheric Progression** | One atmospheric scene per slide, building a mood arc | No — mood must escalate or shift | Stoic Minimalist (bedroom → city → luxury → airplane) |

**Why this matters for derivation**: Information Format is **locked**. A Story must stay a Story, a Zoom must stay a Zoom, a Parallel Contrast must stay a Parallel Contrast. The specific content filling each slot is **open**.

## Text Layer Analysis

Before analyzing text style, first identify **where the text lives**:

| Text Layer | How to recognize | Implications |
|------------|-----------------|-------------|
| **Baked-in** | Text is part of the image file itself (rendered by AI or burned in by editor) | Analyze text style, font, position. Text is soul-level if it carries the humor/emotion. |
| **Overlay** | Text is a separate layer added by a platform (e.g., Museon text_elements, IG text tool) | Image and text are independent. Image must work without text. Text style is platform-dependent. |
| **Absent** | No text on image at all — pure visual storytelling | All meaning comes from imagery. Caption/description carries the narrative instead. |

**Why this matters**: Baked-in text slideshows (memes) need text style analysis. Overlay/Absent slideshows need image-only analysis — skip text style recognition and focus on visual narrative.

## Text Style Recognition

Applies primarily to **Baked-in** text slideshows. For Overlay slideshows, note the overlay style but focus analysis on the image layer.

### Meme Text Formats (Character-Action, Tension-Punchline)

| Format | How to recognize | Vibe |
|--------|-----------------|------|
| **Caption Bar** | Solid white/black bar above or below the image, bold sans-serif, sentence case, casual grammar | Modern TikTok/Twitter meme |
| **Impact Overlay** | Text overlaid on image, ALL CAPS, white with thick black outline | Classic 2010s meme |
| **Subtitle-style** (anti-pattern for memes) | Small white text at bottom with subtle shadow, elegant font | Looks like an ad or movie subtitle — NOT meme |

### Non-Meme Text Formats (Emotional Arc, Mood Showcase)

| Format | How to recognize | Vibe |
|--------|-----------------|------|
| **Minimal serif** | Thin serif font, lots of whitespace, centered, lowercase | Editorial / literary / emotional |
| **Bold statement** | Large bold sans-serif, 1-3 words per slide, high contrast | Motivational / aspirational |
| **Handwritten** | Script or handwriting font, often on solid color background | Personal / intimate / journal-like |
| **No text** | Image only, story told through visuals | Cinematic / atmospheric / mood-first |

### What NOT to Do (recognize these as red flags in analysis)

| Anti-pattern | Why it fails | Archetype |
|-------------|-------------|----------|
| Small white text at bottom with subtle shadow | Looks like a movie subtitle or watermark, not a meme | Character-Action, Tension-Punchline |
| Elegant serif or thin sans-serif | Looks designed/branded, kills meme energy | Character-Action, Tension-Punchline |
| Text in quotes ("like this") | Adds unnecessary formality; memes don't use quotes | Character-Action, Tension-Punchline |
| Text that tries to be "unobtrusive" | Meme text is either boldly present or cleanly separated — never hiding | Character-Action, Tension-Punchline |
| Meme-style ALL CAPS on emotional content | Kills the sincerity; emotional content needs quiet typography | Emotional Arc |
| Too much text on mood images | Breaks the atmospheric spell; mood showcase = image-first | Mood Showcase |

## Linguistic Patterns

Reusable text templates that drive engagement. During analysis, identify which pattern is used. During derivation, keep the pattern and change the fill-in content.

### Humor Patterns (Character-Action, Tension-Punchline)

| Pattern | Template | Mechanism fit | Example |
|---------|----------|---------------|--------|
| **Single-word label** | One word per slide describing the scene | Proxy Expression, Forbidden Release | Case 001: "Work", "Fitness", "Commute" |
| **X not X-ing** | "[noun] not [noun]-ing" | Proxy Expression, Doom Spiral | Case 004: "Brain not braining", "Sleep not sleeping" |
| **Third-person accusation** | "She/He said [claim] but [reality]" | Proxy Expression, Dignity Mismatch | Case 007: "She said she came to study but she's been on TikTok" |
| **Imperative parasocial** | Direct command to viewer: "come closer", "wait for it" | Parasocial Bait-and-Switch | Case 006: "Hey, come closer" |
| **Self-deprecating confession** | "me when...", "POV:", "nobody: / me:" | Proxy Expression | TikTok standard: "me when the deadline is tomorrow" |
| **Escalating list** | Each slide adds a worse item to a list | Doom Spiral | "Monday: fine / Tuesday: okay / Wednesday: [chaos]" |
| **Rhetorical question hook** | Opens with a question the viewer can't resist | Any | "So how has your life been going" (Case 004) |

### Non-Humor Patterns (Emotional Arc, Mood Showcase)

| Pattern | Template | Mechanism fit | Example |
|---------|----------|---------------|--------|
| **POV narrative** | "POV: [emotional situation]" or first-person narration across slides | Emotional Mirror, Transformation Proof | Pet Care: "POV: you adopted bonded siblings" |
| **Silent progression** | No text — images alone tell the story through visual contrast | Aspirational Pull, Emotional Mirror | Skincare Split-Screen: top/bottom contrast needs no words |
| **Aspirational caption** | Short, evocative phrase that labels the mood | Aspirational Pull, Identity Signal | Stoic: "4am. The city is mine." |
| **Curation label** | Category or theme name per slide | Identity Signal, Utility Bookmark | BookTok: "dark romance", "fantasy", "enemies to lovers" |
| **Numbered tip/hack** | "N. [action] — [explanation]" | Utility Bookmark | "3. run it through text-well.com — catches tone issues" |
| **Emotional before/after** | Contrasting captions on paired images | Emotional Mirror, Transformation Proof | "Day 1 at the shelter" vs "Day 365 at home" |
| **Proof-first hook** | Visual evidence of results (scores, data, before/after photos) as opening slide, with methods/tips revealed in subsequent slides | Utility Bookmark, Aspirational Pull | Case 008: 100-score math papers → then study methods. Strongest opener for Rational trigger types — converts skeptics before content begins. |
| **Repeating card template** | Every content slide follows identical structure: [Category Label] + "Best for:" + [Applications + emoji] | Utility Bookmark, Aspirational Pull | Case 008: "Blurting" / "Best for:" / "Biology ✏️ Chemistry 🧪". Creates "card collection" feel — predictability reduces cognitive load, increases swipe willingness. |

Linguistic pattern is often the most transferable element — you can change everything else and the core engagement survives.

## Contrast Stacking (Character-Action only)

Need ≥ 2 dimensions active:

| Dimension | Example |
|-----------|---------|
| Scale | Tiny creature in human-sized world |
| Behavior | Cute subject doing socially taboo action |
| Species-role | Animal doing something its species never would |
| Context | Creature in a setting where it shouldn't exist |

### Behavioral Tier (for spike slides)

| Tier | Type | Shareability |
|------|------|-------------|
| S | Social taboo / vulgar gesture | Highest — "things I want to do but can't" |
| A | Bodily humor | High — universal physical comedy |
| B | Passive-aggressive rebellion | Medium — relatable defiance |
| C | Physical destruction | Low — dramatic but not relatable |

**Rule**: Spike slides must use Tier S or A.

## Ad Integration Analysis

### Core Rules

- Build 3-4+ pure narrative slides before the product
- Ad slide's scene must belong to the same world
- Copy must use the same tone/slang as narrative slides

### Ad Insertion Strategies

Identify which strategy is used during analysis. Strategies are grouped by slideshow type.

**Humor-native strategies** (best for Character-Action and Tension-Punchline):

| Strategy | How it works | Subtlety | Example |
|----------|-------------|----------|--------|
| **Ad-as-punchline** | The product IS the joke's payoff. Removing the ad removes the humor. | 2 (integrated) | Case 006: monkey calling work "monkey behavior" → Kicker AI |
| **Ad-as-resolution** | The product solves the character's problem. The narrative creates a need, the product fills it. | 3 (moderate) | Case 007: "I deserve a break" because Paperpal finished the paper |
| **Ad-as-reward** | After the emotional journey, the product appears as the character's comfort/escape. | 3 (moderate) | Case 004: after doom spiral, cat relaxes with VOMO |
| **Ad-as-background** | Product appears naturally in the scene without being mentioned in text. | 1 (subtle) | Character uses product casually; no text calls it out |
| **Ad-as-final-slide** | Pure narrative slides, then a separate ad slide with different visual treatment. | 4 (overt) | Case 001: hamster's life slides → final slide is hamster using MuseOn |

**Non-humor strategies** (best for Emotional Arc and Mood Showcase):

| Strategy | How it works | Subtlety | Best archetype | Example |
|----------|-------------|----------|----------------|--------|
| **Ad-as-cause** | The product is the reason the "good" state exists. The before/after implies causation. | 2 (integrated) | Emotional Arc | Skincare: glowing skin in "after" slides → product made this happen |
| **Ad-as-lifestyle-element** | The product appears as a natural part of the aspirational lifestyle being showcased. | 1 (subtle) | Mood Showcase | Stoic Minimalist: product on the desk in the cinematic dark room |
| **Ad-as-list-item** | The product is one item in a curated list or grid, presented alongside other genuine recommendations. | 2 (integrated) | Mood Showcase | Productivity Grid: product appears as one of the recommended tools |
| **Ad-as-curation-pick** | The product is featured as part of an aesthetic mood board, endorsed by taste rather than argument. | 1 (subtle) | Mood Showcase | BookTok: product appears alongside curated books and aesthetic images |
| **Ad-as-step** | The product is embedded as one step in a how-to or process list. | 2 (integrated) | Any with Step-by-step format | "7 ways to sound smart in emails" → Step 3: run it through [product] |

### Scoring

| Dimension | Good | Bad |
|-----------|------|-----|
| Narrative fit | Feels like natural story continuation | Feels bolted on |
| Visual consistency | Matches other slides' style | Looks like a different slideshow |
| Copy tone | Conversational, same slang | Marketing-speak |
| Placement | Last or second-to-last | Too early |
| Strategy match | Product naturally fills the chosen strategy role | Product forced into a strategy that doesn't fit |

**Best-in-class by archetype**:
- **Character-Action / Tension-Punchline**: When the ad IS the punchline — structurally inseparable from the joke (see Case 006).
- **Emotional Arc**: When the product IS the cause of the transformation — removing the product removes the hope.
- **Mood Showcase**: When the product IS a natural element of the curated world — it belongs so naturally that calling it an "ad" feels wrong.

### Product-Mechanism Fit

Not every product works with every mechanism. Before committing, ask: "Does my product naturally fill the role this mechanism needs?" See each case's Reusable Blueprint in `cases.md` for concrete examples of what fits and what breaks.

## Soul vs Skin

The most critical skill in analysis and derivation: distinguishing what you **cannot change** (soul) from what you **can freely replace** (skin).

### Soul (LOCKED — change any of these and the slideshow stops working)

| Element | Why it's soul | Example |
|---------|--------------|---------|
| **Trigger type** | The psychological reason people share | Case 006: curiosity ("come closer") — without curiosity, no one swipes |
| **Primary mechanism** | How the trigger is delivered | Case 006: Parasocial Bait-and-Switch — without the "I got played" feeling, no one shares |
| **Information Format** | The content logic between slides | Case 006: Zoom progression — if slides don't get closer, the "come closer" command is meaningless |
| **Visual Continuity strength** | The spatial relationship between slides | Case 006: Strong (zoom) — weak continuity would break the physical "getting closer" experience |
| **Linguistic pattern** | The text template that carries the engagement | Case 004: "X not X-ing" — the grammatical structure IS the joke. Stoic: silent progression — adding text would break the atmosphere |
| **Ad insertion strategy** | How the product connects to the narrative | Case 006: Ad-as-punchline — moving the ad to a separate final slide would kill the self-referential humor |
| **Archetype** | One of four: Character-Action, Tension-Punchline, Emotional Arc, Mood Showcase | Determines which rules, checklist, and vehicle/text norms apply |

### Skin (OPEN — freely replaceable without breaking the mechanism)

| Element | What you can swap | Example |
|---------|------------------|---------|
| **Vehicle** | The specific character/subject | Meme: Cat → raccoon, monkey plush → frog figurine. Emotional: illustrated girl → illustrated boy. Mood: city skyline → mountain cabin |
| **Setting** | Where the scene takes place | Office → kitchen, bedroom → library |
| **Specific content** | What fills the linguistic pattern slots | "Brain not braining" → "Code not coding", "Work" → "Meetings" |
| **Cultural reference** | What cultural context is used | Western office culture → Asian study culture |
| **Text format** | Caption Bar vs Impact Overlay | Visual style choice, doesn't affect mechanism |
| **Visual style** | Photo quality, color palette, era | Phone snapshot → lo-fi illustration (as long as authenticity is maintained) |
| **Number of slides** | How many build slides before the spike | 3 builds → 5 builds (as long as pacing works) |

### The Derivation Rule

> **Keep the soul, reinvent the skin. Change ≥ 2 skin elements to avoid cloning.**

When extracting a blueprint, mark every element as soul or skin. When deriving, verify: "If I remove this element, does the slideshow still trigger the same mechanism for the same reason?" If yes → skin. If no → soul.
