# GeeLark 云端注册与 Agent 协作

把一批账号分给独立云会话，沿用各套设备、邮箱和资料，完成平台操作、原行回填与最终验收。本技能合并了批次协调和单套注册经验；本批团队 SOP 是业务标准，用户明确的流程修订优先。

## 开始前确定本批范围

从用户指定的 SOP、原表与资料库取得批次设备、各平台原记录、资料分配规则、并发上限及结果投递位置。核实本批外部写入、消息投递、权限变更和定时更新的明确授权；同一授权范围内不反复询问。历史批次的环境 ID、账号、授权和统计不能直接用于新批次。

云端凭据由环境配置或批准的 secret store 提供。技能、交接正文、仓库和报告只保留变量名及读取方式。先验证云环境能读必要服务、执行允许的设备控制并写回指定原行，再铺开并发。

## 按工作阶段读取

- **批次协调**：读 [云会话调度](references/cloud-coordination.md)，分配任务、确认真正启动、自动补位、替换卡住的会话并按约定检查。
- **单套执行**：读 [单套注册](references/account-execution.md)，按 Facebook 浏览器 → Instagram Lite → Instagram 网页兜底接续 Meta 流程，并完成 YouTube、TikTok。
- **连接或回填**：读 [接口与记录契约](references/interfaces-and-writeback.md)，核对 GeeLark、ADB、资料库及飞书的实际接口。
- **阻塞、人工交接与汇总**：读 [验证、排障与验收](references/verification-and-review.md)，区分验证码类型、提供单台云机访问链接、统计可解释的结果。

## 协作中的固定关系

一套账号对应一台 GeeLark 设备、一个登记邮箱、一份资料包及四个平台原行；每套同一时间只有一个负责操作和回填的云会话。重试、更换 Agent 或云运行实例时沿用这套关系。

协调器维护任务归属、分配和汇总；执行 Agent 写自己的原行并回读。成功、人工验证、封禁和技术待处理分别记录。本人主页、资料完整性、密码是否实测可登录是不同的验收项。

技能已随任务交接时，缺少同名本地 skill 或 CLI 不等于未授权；用任务内可读材料和当前获准接口继续。最后按本批要求核实设备关机；交给用户手动验证的设备单列为交接中。
