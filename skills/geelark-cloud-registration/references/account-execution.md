# 单套账号如何执行

## 接手和准备

读取本套四个平台原行、登记邮箱、资料包绑定及已登记的实际密码。核对设备当前状态与 Google / 平台会话，已有成功结果保持，未完成项从实际页面继续。手机、邮箱、资料包及记录归属不能因换 Agent 而改变。

新资料按资料库的实时 agent guide 领取，写入设备绑定后回读；已分配资料沿用原编号。头像、简介、姓名和生日按同组资料与 SOP 使用，生日差 1–2 天是否接受由本批要求决定，不自行推广为其他任务的容差。

凭据从原行或云端配置读取，含凭据的输入命令与界面不回显。用正确邮箱/既有用户名核实账号状态；官方确认未建号才注册，特别注意注册报错后账号可能已在服务端创建。

## Meta 按这个顺序接续

### Facebook 浏览器

在本台云机 Chrome 注册或登录 Facebook，使用本套登记邮箱。官方确认已有 Meta 账号但尚无 Facebook profile 时，按官方恢复或新增 profile 流程接续，而不是另建重复 Meta 账号。普通条款按本批授权处理；点击后若返回注册错误，要记录实际响应，不能只记“停在条款页”。

网页成功后按 SOP 核对 Facebook App 本人主页、头像、简介和真实主页链接。浏览器和 App 可能有不同验证结果，分别记验收阶段。Facebook 受阻仍继续 Instagram。

### Instagram Lite

Facebook 成功时先核对对应账号的 `Continue as`。入口未出现时，从最近任务移除 Lite 后重开一次；Facebook 未成功或仍无关联入口时，按登记邮箱接续独立注册/登录。

遇到 `Something went wrong` 或最终提交无反馈，先核实既有账号状态，不能直接重复注册。原生日期控件的 `set_text` 或点击可能静默无效，必要时用 ADB 手势，最终以页面显示日期为准。

### Instagram 官方网页兜底

Lite 入口持续加载、按钮不可用或流程不能推进时，在同台云机 Chrome 进入官方注册/登录。已有账号走登录或官方恢复；只有明确查无账号才注册。网页本人主页及资料核验通过即可按本批要求登记，不能额外要求 App 登录才能算网页成功。

若原表只有 `Confirm you're human`，需要时可打开后续说明以识别验证类型，但不识别、填写或提交 CAPTCHA。人工交接见验证参考。

## YouTube

沿用核对过的 Google 会话，确认/创建本人频道；在 `How you'll appear` 核对头像，从 `You → View channel → Edit channel` 补原简介。保存后重开核对全文与真实频道 URL，不能用头像会话已存在代替资料验收。

## TikTok

使用 `Continue with Google` 时核对选中的登记账号。生日滚轮停稳后读完整日期；昵称提交后判断是否真正进入本人 Profile。

Google Play 附加资源弹窗、地区不可用、登录回跳和账号封禁是不同结果。必要组件通过官方正常安装/更新处理；可选提示按本批要求关闭。官方网页登录可用于核实原账号；记录真实 HTTP 响应及平台提示，限流时按要求等待。

本人 Profile 核对头像、完整简介、用户名，从分享或 `Your QR code` 取得真实链接。保存头像时关闭可选 `Post this photo to Story`，其他平台同样核对可选 Feed/Story 分享。

## 保存资料和凭据

- 头像先确认已进入本机图库，再在本人主页核对保存结果。
- 简介含非 ASCII 字符或表情时，使用原生键盘、正常系统剪贴板等设备支持的输入方式；重开编辑页逐字核对。不能因某次键盘搜不到某个表情就认定设备永远不支持。
- 实际提交密码及时保存对应平台原字段并回读，区分邮箱密码、平台密码和共享 Meta 恢复密码。官方共享密码恢复确实影响多个 profile 时，按明确影响范围同步；不能凭猜测复制 Instagram 密码到 Facebook。
- “已提交密码”“确认改密生效”“实际密码登录成功”是不同证据；只有最后一项才能标为密码已验证。

## 每个平台结束后

按接口参考回填对应原行并回读。本人主页可见、资料完成、凭据验证分别说明。实际人工验证/封禁保留真实原因；技术故障保留已完成步骤与剩余项，继续其余可独立完成的平台。

全组结果回读后，依据实时资料库指南标记资料已使用；待接续的组保留原占用。设备按本批约定关机并回读 `status=2`；正在交给用户手动操作时保留开机和唯一拥有者，用户完成后再检查、收尾。
